# Summary: Creating a Spec Kit Constitution Non-Interactively

Use one-pass constitution creation when the project's governing principles are already known and approved. Initialize Spec Kit for the selected agent, invoke the `speckit-constitution` skill inside the agent chat, and provide the principles with their scope, rationale, and validation expectations. This is different from the terminal flag `specify init --non-interactive`, which only prevents the CLI initializer from asking questions. In the lesson example, “minimal dependencies,” “documentation-grounded development,” and “lightweight operation” must be refined into enforceable rules covering dependency approval, official version-specific sources, and explicit resource budgets or visible TODOs. Review the generated `.specify/memory/constitution.md` even when creation is quick. The constitution can later be amended with an appropriate semantic version change before the project proceeds to feature specification.
