# Summary: GitHub Spec Kit Process Flow

GitHub Spec Kit structures complex AI-assisted development around durable project artifacts. A constitution establishes project-wide principles, while each substantial feature moves through specification, optional clarification, technical planning, task decomposition, implementation, and convergence. The key separation is that `specify` defines what should be built and why, while `plan` decides how to build it. Optional `checklist` and `analyze` stages improve requirements quality and cross-artifact consistency before coding. Spec Kit is most useful for features that require planning and coordinated changes, not trivial edits. Because accepted decisions are stored in Markdown files, developers can reset the agent's context between stages to reduce token use and keep later work focused, provided the next session rereads the constitution and current feature artifacts.
