# Summary: Installing GitHub Spec Kit

GitHub Spec Kit supports spec-driven development in both new and existing projects. Its installation involves two different tools: `uv` is the recommended Python package and tool manager, while `specify` is the executable provided by the package named `specify-cli`. After confirming Python 3.11 or newer, install `uv` using an approved operating-system or Python-based method, verify it with `uv --version`, and install Spec Kit with `uv tool install specify-cli`. For a reproducible team setup, the official guide also supports installing a release pinned by its GitHub tag. Confirm the result with `specify version` before initializing a project. In existing repositories, commit or back up work and review all generated changes. Do not disable corporate security controls to make an installer run; use an approved package source or ask the responsible team for access.
