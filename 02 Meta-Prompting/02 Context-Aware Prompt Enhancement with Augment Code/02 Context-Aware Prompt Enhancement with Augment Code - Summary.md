# Summary: Context-Aware Prompt Enhancement

Context-aware prompt enhancement combines a concise developer request with relevant information retrieved from the current repository. Unlike a generic enhancer that improves only wording and structure, a context engine such as Augment Code can identify related files, existing behavior, project conventions, and likely modification points. In the lesson, Augment Code expands a short token-usage request, Codex implements it, and the compiled Go Agent successfully displays input- and output-token counts. Because the original request did not define their exact presentation, Codex chooses a simple display itself. Better context can improve first-attempt results, but it does not replace product decisions, engineering judgment, security review, code review, or testing. The key skill shifts from memorizing prompt formulas to stating intent clearly, validating retrieved context, adding requirements that the code cannot reveal, and verifying the implementation.
