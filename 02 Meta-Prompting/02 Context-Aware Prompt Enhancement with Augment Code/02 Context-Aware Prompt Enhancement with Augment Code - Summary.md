# Summary: Context-Aware Prompt Enhancement

Context-aware prompt enhancement combines a concise developer request with relevant information retrieved from the current repository. Unlike a generic enhancer that improves only wording and structure, a context engine such as Augment Code can identify related files, existing behavior, project conventions, and likely modification points. The enhanced prompt should be reviewed as a proposed implementation plan and can then be executed by the same tool or passed to another coding agent. Better context can improve first-attempt results, but it does not replace engineering decisions, security review, code review, or testing. The key skill shifts from memorizing prompt formulas to stating intent clearly, validating retrieved context, adding requirements that the code cannot reveal, and verifying the implementation.
