# Summary: Meta-Prompting with NotebookLM

NotebookLM can act as a source-grounded meta-prompting layer that transforms informal input—such as voice recordings, meeting notes, rough user stories, documents, web pages, or public captioned videos—into structured artifacts for AI-assisted development. A developer can use it to draft a product requirements document, technical task, engineering standard, or set of project principles, then review the output before passing it to a coding agent. The lesson demonstrates adding a public video about NASA-style software practices, generating an engineering standard from it, and adapting the reviewed principles into a GitHub Spec Kit project constitution. The essential workflow is to capture intent, select relevant sources, request the correct artifact, verify source grounding, remove unsuitable assumptions or rules, and validate every downstream result.
