# Summary: Creating Your First Product Requirements Document

The `snarktank/ai-dev-tasks` repository provides reusable Markdown prompts for turning a feature idea into a reviewed Product Requirements Document and then into an implementation task list. The `create-prd.md` workflow asks a small set of essential clarifying questions before generating a PRD with goals, user stories, functional requirements, non-goals, success metrics, and open questions. After the developer reviews the PRD as the feature's source of truth, `generate-tasks.md` creates high-level tasks, pauses for approval, and then expands them into actionable subtasks and relevant files. This is a practical meta-prompting and spec-driven development workflow: define the product before coding, review third-party prompt instructions, resolve assumptions explicitly, and implement the approved plan in small, verifiable steps.
