# Summary: Current Toolset for AI-Assisted Development

This lesson presents a June 2026 snapshot of the course's three primary AI development tools: Claude Code, OpenAI Codex, and Google Antigravity. Claude Code helped establish many modern agent features, Codex combines broad command-line capabilities with generous usage limits, and Antigravity provides a Google-backed CLI and IDE with access to Google and Claude models. The tools can be used through combinations of terminals, desktop applications, editor extensions, and dedicated IDEs. The best choice depends on output quality, cost, limits, and personal workflow, while every terminal-based agent requires careful supervision because it can run commands and modify the codebase. Because the ecosystem changes quickly, current models, prices, limits, and interfaces should be checked before choosing a tool.
