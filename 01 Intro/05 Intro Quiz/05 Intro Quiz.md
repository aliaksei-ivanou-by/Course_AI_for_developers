## Questions, Answers, and Feedback

### 1. Which group of features is strongly associated with Claude Code's influence on other AI development tools?

- A. Static analysis, dependency locking, code formatting, and compilation
  - **Feedback:** Incorrect. These are established development processes and are not presented as features introduced or popularized by Claude Code.
- B. Subagents, MCP, agent skills, and hooks
  - **Feedback:** Correct. These capabilities became strongly associated with Claude Code and later appeared in tools such as Codex and Antigravity.
- C. Database replication, browser automation, image editing, and monitoring
  - **Feedback:** Incorrect. These may be useful technical capabilities, but they are not the group of features identified in the lesson.
- D. Cloud hosting, issue tracking, container registries, and package publishing
  - **Feedback:** Incorrect. These are general software-development services, not the agent features highlighted as Claude Code innovations.

**Correct answer:** B. Subagents, MCP, agent skills, and hooks.

  - **Feedback:** Incorrect. Prototype migration is discussed as a course example, but not as the main reason prompt engineering remains important.
- C. When replacing software testing with chatbot conversations
  - **Feedback:** Incorrect. The transcript does not say prompt engineering replaces testing.
- D. When building AI-powered solutions that need protection and control
  - **Feedback:** Correct. The instructor says prompt engineering is still needed for AI-powered solutions, especially customer-facing systems that require safeguards.

**Correct answer:** D. When building AI-powered solutions that need protection and control.

  - **Feedback:** Incorrect. Codex and Claude Code can operate inside Visual Studio Code itself.
- C. Only through a browser connected to the repository
  - **Feedback:** Incorrect. A browser is not required for the terminal or extension workflows described.
- D. Only by installing GitHub Copilot first

### 10. What organizational control is recommended for MCP server usage?

- A. Permit only servers that expose administrative write access
  - **Feedback:** Incorrect. Administrative access increases risk and should be granted only when necessary.
- B. Maintain a whitelist of reviewed and approved MCP servers
  - **Feedback:** Correct. A whitelist allows the organization to control which servers, versions, and configurations employees may use.
- C. Allow employees to connect any server as long as it is open source
  - **Feedback:** Incorrect. Open-source availability does not guarantee that a server is secure, correctly configured, or free from harmful commands.
- D. Store all MCP credentials in a shared public configuration file
  - **Feedback:** Incorrect. Credentials must be protected and should never be placed in a public file.

**Correct answer:** B. Maintain a whitelist of reviewed and approved MCP servers.
