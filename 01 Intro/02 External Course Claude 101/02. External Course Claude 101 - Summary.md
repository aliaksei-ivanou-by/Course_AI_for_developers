# Summary: External Course — Claude Code 101

This lesson directs learners to the external Claude Code 101 course, which takes approximately 90 minutes. The course introduces Claude Code, installation and first prompts, the explore–plan–code–commit workflow, context management, code review, and customization through `CLAUDE.md`, subagents, skills, MCP, and hooks. A Claude subscription is not required: the exercises can also be practiced with another modern AI coding tool available through a subscription, free plan, or trial.
