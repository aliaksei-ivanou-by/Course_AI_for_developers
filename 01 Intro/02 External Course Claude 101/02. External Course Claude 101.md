# External Course: Claude Code 101

**Estimated time:** approximately 90 minutes  
**Course:** [Claude Code 101](https://anthropic.skilljar.com/claude-code-101)

## Course Details

Register at [Anthropic Skilljar](https://anthropic.skilljar.com) using your Innowise email account and complete the [Claude Code 101 course](https://anthropic.skilljar.com/claude-code-101).

The course covers the basics of the Claude Code CLI agent. Most of its functionality overlaps with other modern AI coding tools, such as Codex, OpenCode, Factory, and Pi.

## Claude Subscription Notice

You do not need a Claude subscription to complete the course.

If you want to practice the exercises, you can use another tool available through a paid subscription, a free plan, or a free trial. Claude Code sets standards followed by AI coding agents, so its core functionality is also available in other modern AI coding tools.
