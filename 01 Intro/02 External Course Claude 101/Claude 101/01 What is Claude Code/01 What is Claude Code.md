# What Is Claude Code?

Claude Code is an agentic coding tool that understands your codebase, edits files, runs commands, and integrates with existing developer tools to help you get things done faster. It is available in the terminal, Visual Studio Code, the Claude Desktop app, on the web, and in JetBrains IDEs.

## What Separates Claude Code from Claude?

If you have used Claude.ai before, you might wonder what makes Claude Code different. Unlike Claude.ai, Claude Code has direct access to your files, terminal, and entire codebase. Instead of requiring you to copy and paste code back and forth, it can enter the development environment and do the work itself.

The key differentiator is that Claude Code works as an AI agent.

## What Is an Agent?

An AI agent is software that can interact with its environment and perform actions to complete a defined goal. At its core, a large language model operates in a real-time loop. AI agents can access tools, external services, and even other AI agents to help them achieve their goals.

## What Can Claude Code Do?

- **Read and understand a codebase.** You can ask Claude Code to explain a feature or trace a bug throughout the code.
- **Edit files across a project.** Claude Code can refactor a function and update every file that references it.
- **Run terminal commands.** It can execute a build script, run tests, install packages, and use the output to decide what to do next.
- **Search the web.** If it needs documentation or the latest API references, it can look them up.

## Using Claude Code Effectively

Keep these three concepts in mind:

1. **The context window is Claude's working memory.** It can hold a lot, but not everything at once. The agentic approach allows Claude to locate information strategically within a codebase without loading the entire project into context.
2. **Claude Code asks for permission.** By default, it asks before running commands or making changes. You remain in control, whether you prefer a hands-on or hands-off approach.
3. **Claude Code can make mistakes.** It may misunderstand your intent, introduce a bug, or over-engineer a solution. Staying involved helps you catch these problems early.

## Recap

Claude Code is an agentic coding tool. It reads your codebase, edits files, runs commands, and connects to external tools to help you deliver work faster. You can use it in the terminal, VS Code, JetBrains IDEs, and the Claude Desktop app.
