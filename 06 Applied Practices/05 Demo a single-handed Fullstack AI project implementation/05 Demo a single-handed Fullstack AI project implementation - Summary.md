# Case Study: A Single-Developer Full-Stack AI-First Project — Summary

*Practice Perfect* was an MVP for sports coaches—events, CRM, payments, forms, roles, and video content—delivered as a deployed, functional platform in about 300 hours by a project manager/business analyst, one full-stack AI developer, a developer intern doing manual QA, a designer for about ten hours, and a delivery lead. It broke even financially but produced practical lessons. An AI-expanded 82-page specification contained an estimated 30% hallucinated content, and starting development before requirements were fixed created "instant legacy": removed features and old designs kept resurfacing, and small changes cost about as much as new features. The team recovered by moving specifications into a file-based repository with meta rules, untouched client sources, epics with user flows, a project plan, and meeting transcripts automatically turned into decisions and closed questions; changes became atomic descriptions or new epics instead of rewrites. Specifications for AI must avoid forward references between epics and describe integrations such as Stripe precisely. Manual QA remained essential because AI wrote both code and tests from the same flawed requirements, and an agent once reported a feature done with its frontend missing. With CLI access, the agent resized a cloud machine and raised costs from about USD 4 to 25 per day, so cloud changes must go through reviewed Infrastructure as Code with budgets and regular checks. Dedicated AI accounts, explicit architecture decisions for handover, and experienced people in every role are prerequisites: AI multiplies expertise; it does not replace it.
