# Innowise Accelerator for Structured AI-Assisted Development — Summary

Innowise Accelerator is a stack-aware framework that organizes AI-assisted engineering into isolated tasks, reusable skills, explicit human gates, persistent artifacts, review, and verification. The workshop demonstrated an internal Node.js, NestJS, React, and Next.js version centered on Claude Code; the lesson also includes `embacc` v2.6.0 from the public [innowise-ai/cpp-embedded-accelerator](https://github.com/innowise-ai/cpp-embedded-accelerator) repository. This C++ / Embedded port provides reusable workflows for architecture, implementation, code review, testing, debugging, performance profiling, and target verification. It supports Claude Code, Codex, OpenCode, and Pi, ships 17 canonical workflow skills, and normally keeps generated `PROJECT.md`, task `STATE.md`, learned skills, integration configuration, and other state under `~/.embacc` instead of the client repository. Its optional `install` command can add reviewed shared configuration to a repository using hash-based ownership and conflict preservation. The included deterministic suite passed all 13 local test modules, while external-agent, real Pixi update, dynamic Pi, and live `ast-grep` checks were not run in the available environment. The package metadata says `Proprietary` and the snapshot has no standalone `LICENSE`, so the lesson links to the upstream source without describing it as open source. Neither implementation should be mistaken for a fully autonomous or inherently secure system: developers remain responsible for requirements, permissions, architecture, target evidence, review, tests, privacy, accessibility, compliance, and integration. The safest adoption path is a bounded pilot measured by verified quality, lead time, rework, cost, and maintainability rather than demo speed or generated code volume.
