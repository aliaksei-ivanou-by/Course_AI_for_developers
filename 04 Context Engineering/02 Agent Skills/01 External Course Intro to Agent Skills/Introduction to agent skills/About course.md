# Introduction to Agent Skills: About the Course

Introduction to Agent Skills is designed for developers and teams that want to stop repeating the same guidance and turn it into reusable capabilities for Claude Code. The six-lesson course covers everything from creating a first Skill to advanced configuration, team distribution, and troubleshooting.

The course is available through Claude Academy and takes approximately one hour to complete. Learners taking the course through their company or employer can continue using the existing course site.

## Learning Objectives

By the end of this course, you will be able to:

- Explain what Skills are, where they live, and how Claude Code matches them to requests.
- Create a Skill from scratch with valid `SKILL.md` frontmatter and verify that it loads.
- Write effective Skill descriptions and restrict tool access with `allowed-tools`.
- Organize larger Skills using progressive disclosure, reference files, and executable scripts.
- Choose between Skills, `CLAUDE.md`, subagents, hooks, and MCP servers for a given use case.
- Share Skills through project repositories, plugins, enterprise managed settings, and custom subagents.
- Diagnose triggering, loading, priority-conflict, and runtime issues with the skills validator and `claude --debug`.

## Prerequisites

- Basic familiarity with a code editor and the command line.
- Basic knowledge of Markdown, files, and directories.
- Access to Claude Code or another coding agent that supports Agent Skills for hands-on practice.

## Who This Course Is For

This course is intended for developers, technical leads, and AI-assisted development teams that want to create a Skills-based workflow that keeps Claude consistent, context-efficient, and aligned with their working standards.

## Data and Privacy

### What Is Skilljar and Why Am I Logging In to It?

Skilljar is a learning management system that hosts the educational content. You log in to Skilljar to access the Anthropic course materials. The platform provides interactive learning experiences, tracks course progress, and organizes the course resources.

### What Information Does Skilljar Collect About My Learning Activity?

Skilljar collects basic learning analytics, including course progress, lesson completion status, quiz scores, and time spent on materials. This information supports progress tracking and course completion certificates. The data collection is focused on improving the learning experience and is subject to Skilljar's Privacy Policy.

### How Is Skilljar Data Different from Anthropic Account Data?

Skilljar tracks learning progress within the course platform. An Anthropic account manages access to the Anthropic Console and Claude AI services.

### Is Skilljar Secure and Where Is the Data Stored?

Skilljar uses industry-standard security measures, including data encryption, secure hosting, and regular security audits. Learning data is stored on secure servers with access controls. Skilljar is SOC 2 compliant and follows data-protection best practices.

### How Can I Delete My Learning Activity or Account?

To request deletion of learning data or an account, email [academy-support@anthropic.com](mailto:academy-support@anthropic.com). Requests are processed in accordance with applicable privacy laws and data-retention policies. Some data may need to be retained for legitimate business purposes, such as compliance or security, but personal information will be deleted where legally permissible.

### Do I Need an Anthropic Account to Access the Learning Content?

No. Access to the learning content requires only a Skilljar account. An Anthropic account is separate and is required only to use Claude AI services after completing the course.
