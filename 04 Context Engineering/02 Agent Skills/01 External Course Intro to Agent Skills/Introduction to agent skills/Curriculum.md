# Introduction to Agent Skills Curriculum

The course contains six lessons and takes approximately one hour to complete.

## Course Overview

### 1. What Are Skills?

1. [What Are Skills?](01%20What%20are%20skills/01%20What%20are%20skills.md)

### 2. Creating Your First Skill

1. Creating a Skill from scratch
2. Writing valid `SKILL.md` frontmatter
3. Verifying that the Skill loads

### 3. Configuration and Multi-File Skills

1. Writing effective descriptions
2. Restricting tool access with `allowed-tools`
3. Organizing larger Skills with progressive disclosure
4. Adding reference files and executable scripts

### 4. Skills vs. Other Claude Code Features

1. Skills vs. `CLAUDE.md`
2. Skills vs. subagents
3. Skills vs. hooks
4. Skills vs. MCP servers

### 5. Sharing Skills

1. Sharing Skills through project repositories
2. Distributing Skills through plugins
3. Deploying Skills with enterprise managed settings
4. Using Skills with custom subagents

### 6. Troubleshooting Skills

1. Diagnosing triggering and loading problems
2. Resolving priority conflicts
3. Investigating runtime errors
4. Using the skills validator and `claude --debug`
