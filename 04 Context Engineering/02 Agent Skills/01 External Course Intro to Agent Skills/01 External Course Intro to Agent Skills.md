# External Course: Introduction to Agent Skills

**Estimated time:** approximately 1 hour  
**Course:** [Introduction to Agent Skills](https://academy.claude.com/courses/introduction-to-agent-skills)

## Course Details

Complete the [Introduction to Agent Skills course](https://academy.claude.com/courses/introduction-to-agent-skills) on Claude Academy.

The six-lesson course explains how to build, configure, and share reusable Skills in Claude Code. Skills package Markdown instructions and optional supporting resources that Claude applies automatically to matching tasks.

The course progresses from creating a first `SKILL.md` file to distributing Skills across teams and troubleshooting common issues. The material uses Claude Code for demonstrations, but the core concepts also apply to other coding agents that support Agent Skills or a comparable skill system.

## Claude Subscription Notice

You do not need a paid Claude subscription to read the course materials on Claude Academy.

If you want to practice the Claude Code exercises directly, you need access to Claude Code. You can also adapt the exercises to another coding agent that supports the Agent Skills standard or an equivalent skill system.

## Curriculum

### Course Overview

- What Agent Skills are
- Where Skills live and how Claude Code matches them to requests

### Creating Skills

- Creating your first Skill
- Writing valid `SKILL.md` frontmatter and verifying that the Skill loads
- Writing effective descriptions and configuring `allowed-tools`
- Organizing multi-file Skills with progressive disclosure, reference files, and scripts

### Skills and Other Claude Code Features

- Skills vs. `CLAUDE.md`
- Skills vs. hooks
- Skills vs. subagents
- Skills vs. MCP servers

### Sharing and Troubleshooting

- Sharing Skills through repositories, plugins, enterprise managed settings, and custom subagents
- Troubleshooting activation, loading, priority-conflict, and runtime issues
- Using the skills validator and `claude --debug`

The course materials are organized in the structured [curriculum](Introduction%20to%20agent%20skills/Curriculum.md).
