# Introduction to Subagents: About the Course

Introduction to Subagents is designed for developers who want to delegate focused work without filling the main conversation with search results, logs, intermediate reasoning, or file contents that are no longer needed. The course explains how specialized assistants work in separate context windows and return only the information required by the parent conversation.

The course is available through Claude Academy, contains four lessons, and takes 45 minutes to complete. Learners taking the course through their company or employer may continue using the existing course site.

## Learning Objectives

By the end of this course, you will be able to:

- Explain how subagents work, including how Claude Code creates a separate context, passes inputs, and receives summaries.
- Create custom subagents with the `/agents` command for workflows such as code review and documentation generation.
- Design reliable subagents with structured output formats, obstacle reporting, focused responsibilities, and limited tool access.
- Decide when subagents provide useful isolation and recognize common delegation anti-patterns.

## Prerequisites

- Basic familiarity with Claude Code or another AI coding agent.
- Basic knowledge of files, directories, Markdown, and YAML.
- Command-line experience is helpful but not required.
- Access to Claude Code or a comparable agent environment is required for hands-on practice.

## Who This Course Is For

This course is intended for developers, technical leads, and AI-assisted development teams that want to keep long sessions focused, delegate specialized work, and build repeatable multi-agent workflows.

## Version Notice

The course describes creating subagents with the `/agents` command. Claude Code's interface evolves: in current versions, you can ask Claude to create the definition or edit Markdown files under `.claude/agents/` or `~/.claude/agents/` directly. Check the [current subagent documentation](https://code.claude.com/docs/en/sub-agents) while completing hands-on exercises.
