## Course Details

Complete the four-lesson, 45-minute [Introduction to Subagents course](https://academy.claude.com/courses/introduction-to-subagents) on Claude Academy.

The course explains how Claude Code delegates focused tasks to specialized assistants with separate context windows. Subagents perform work independently and return concise results to the main conversation, helping keep long sessions focused and context-efficient.

The material covers creating custom subagents, designing reliable instructions and output formats, limiting tool access, reporting obstacles, choosing appropriate delegation scenarios, and avoiding common anti-patterns.

## Curriculum

### What Are Subagents?

- What subagents are
- How separate context windows preserve the main conversation
- How inputs flow to a subagent and summaries return

### Creating a Subagent

- Creating custom subagents for code review and documentation
- Defining focused instructions, tools, and scope
- Invoking a subagent for a matching task

### Designing Effective Subagents

- Requiring structured outputs
- Reporting obstacles instead of silently failing
- Limiting tool access and keeping responsibilities focused

### Using Subagents Effectively

- Choosing tasks that benefit from isolated delegation
- Decomposing and parallelizing complex work
- Recognizing situations where a subagent adds unnecessary overhead
