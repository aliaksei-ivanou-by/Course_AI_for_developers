# Summary: Context Window Size and Model Performance

An advertised context window is a capacity limit, not a target occupancy. The model's effective context depends on whether the available material is sufficient, relevant, current, structured, and free of conflicting history. *Lost in the Middle* describes a positional weakness observed in long-context experiments: models often use relevant information near the beginning and end more reliably than information buried in the middle. The pattern and its magnitude vary by model and task, so neither 100,000 tokens nor any fixed percentage is a universal performance threshold. Monitor absolute and relative context use, load focused evidence, structure critical requirements clearly, persist durable state in project files, compact when continuing the same objective, and start a new session when the objective changes. Optimize for correct end-to-end task completion rather than the smallest possible prompt.
