# Summary: Generating Project Instructions for Coding Agents

Project instruction files preserve stable repository context across agent sessions. In Codex, `/init` generates an `AGENTS.md` scaffold in the current directory, but the result must be reviewed: verify every command, path, architectural claim, safety boundary, and validation rule before committing it. Keep instructions concise, route to deeper documentation only when relevant, and avoid secrets, task-specific requirements, generated repository maps, and rules already enforced by tools. Codex combines global and project instructions from the repository root toward the current working directory; nested guidance has greater precedence, and `AGENTS.override.md` wins over `AGENTS.md` at the same level. Other agents may use files such as `CLAUDE.md` or `GEMINI.md`, so shared content can use a canonical source only when each tool's import or discovery behavior has been verified. Agent instructions complement rather than replace Spec Kit constitutions, specifications, plans, and tasks.
