# Summary: Monitoring Context and Token Usage

A coding-agent status line is an observability tool: it shows session state but does not manage context automatically. In Codex, a practical footer displays the model and reasoning level, context remaining, current directory, and Git branch; `/statusline` configures the footer, while `/status` provides deeper session details. Context-window capacity, current occupancy, cumulative session tokens, rate limits, and billable usage are separate measurements, so a context percentage or token counter is not an exact cost figure. Keep sessions focused, persist durable decisions in repository files, compact when continuing the same objective, and start or fork a session when the objective changes. In the Claude Code version shown in the lesson, verbose output exposes usage details and `/context` visualizes context consumption, but these interface details should be verified against the installed release.
